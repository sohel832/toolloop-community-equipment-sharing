# ToolLoop Frontend

Next.js 14 + React.js + Tailwind CSS frontend for **ToolLoop — Community Equipment-Sharing Network**.

### Features:
- Equipment catalog with categories & condition filters
- Borrowing modal with date picker and refundable deposit calculation
- Lending modal to list new equipment
- Booking management (Approve / Decline / Return / Refund)
- Ratings & Reviews system (1-5 stars)
- Community Hubs join/leave
- Live MySQL DBMS Explorer with SQL console

### Running Frontend:
```powershell
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
